# Project Memory

## Core
CodeSage - free coding learning platform for students. Supabase auth + profiles table. Dark purple-blue theme.
Primary orange #e98a2e, accent purple. JetBrains Mono + Inter fonts. Glassmorphism UI.
Backend/AI sections locked by default, unlockable via promo codes.
Duolingo-style progression: lessons unlock sequentially, level tests gate next level.

- [Lesson system](mem://features/lessons) — Basics/Intermediate/Expert with sequential unlock, inline challenges, level tests at 70% pass. Includes multimedia, forms, accessibility, real-world projects.
